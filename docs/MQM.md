# MQM 类型

## 总览

- **准确 `accuracy`** 判命题内容、言外之意和术语是否一致。
- **通顺 `fluency`** 判句子是否成立、自然、可读。
- **得体 `fit`** 判表达是否适配元素类型、语域、语气、设定和项目约定。
- **排版 `design`** 判占位符、格式码、格式约定和长度是否合规。
- **中性 `neutral`** 记上游缺陷与存疑问询，不作质量判罚。

## 准确 `accuracy`

准确只判命题内容、言外之意与术语，不判句子顺不顺。

- `accuracy/mistranslation` **错译**
  - 译文把原文的否定、指称、数量、关系或反义译错了。
- `accuracy/omission` **漏译**
  - 译文丢了原文的整句、从句、限定成分或条件，甚至整条输出为空。
- `accuracy/addition` **增译**
  - 译文多出原文没有的解释、额外推测或私货，擅自破坏信息差、叙事留白。
  - 必要的语法显化、或为满足控件功能所作的改写增补（参见 `fit/function`）不算增译。
- `accuracy/untranslated` **未译**
  - 该译的内容仍是英文。
  - 品牌名、模组名、代码变量和刻意保留的部分不算未译。
- `accuracy/do-not-translate` **应留原文**
  - 译文译出了保留清单里明确要求保留原样的内容。
- `accuracy/terminology` **术语不符**
  - 译名与给出的参考术语表、社区常用译法不符。
  - 译文在同词多义时选错了义项。

## 通顺 `fluency`

通顺只判句子是否成立、自然、可读，不判意思对不对。

- `fluency/grammar` **语法**
  - 译文句子成分残缺、语序颠倒、主谓/动宾搭配不当。
- `fluency/awkward` **生硬**
  - 译文句子语法成立，但读来有浓重翻译腔，显得冗余、生硬或拗口。
  - 常见于机械直译导致的冗余堆砌：如“对敌人进行攻击”（应直接为“攻击敌人”）、“当被右击时”（过度被动）、“点击它以将其激活”（代词赘余）、或长定语层层套“的”。
- `fluency/punctuation` **标点**
  - 译文标点误用，引号或括号不配对，句末标点缺失，断句读错。
- `fluency/typo` **错别字**
  - 译文出现错字、别字、拼音同音误选或形近字误用。

## 得体 `fit`

得体只判这话放在这个位置、这个场景合不合适，不判意思对不对。

- `fit/function` **功能不符**
  - 译文没有履行该场景下的职责。
  - `Yes / No`：对话里可译作“好/不”“好的/不要”，按钮上应译作“是/否”。
  - `Keep Off the Grass`：按字面是“远离草地”，立在草地上作为告示语则应表达为“请勿践踏草坪”。
  - 导航控件的 `Back` 应译作“返回”，而非“后方”。
- `fit/register` **语域不符**
  - 译文的文白程度与称谓层级不合文本类型或既有口吻，休闲文案用了书面语，你/您混用。
- `fit/tone` **语气不符**
  - 译文没译出原文的讽刺、紧急、玩笑、亲昵、威严或傲慢语气。
- `fit/culture` **文化错位**
  - 译文意象与虚构设定或目标文化冲突。
  - 中世纪奇幻里出现了现代网络用语，西幻里出现了中式典故。
- `fit/convention` **体例不符**
  - 译文违反了项目风格指南（STYLE.md）约定的构词规范、句式体例或交互文本标准。
  - 构词法不合规范（如物品/实体命名未遵从统一构词，动名词与动宾短语混用）。
  - 同类交互文本句式模板不一（如 Tooltip、按键引导在祈使句、短语和完整句之间混杂）。
  - 常见系统提示或操作引导未采用项目约定的统一样板句式，被随意自由发挥。

## 排版 `design`

排版只判占位符、格式码、格式约定和长度，不判措辞。

- `design/markup` **标记错误**
  - 译文里的占位符、格式码或标签有缺失、错位或语义错误。
  - 如 `%s`, `{0}`, `\n`, `§a`, `<color>`
- `design/format` **格式不符**
  - 全半角、中英混排空格或大小写与项目约定不符。
- `design/length` **长度超限**
  - 译文超出按钮、提示框、物品名或界面的可用显示物理长度，导致截断或遮挡。

## 中性 `neutral`

中性不判译文过错，不作扣分。仅用于记录上游缺陷或发起问询。

- `neutral/source` **原文问题**
  - 原文本身有错误、歧义、占位符不全或不适宜内容。
- `neutral/query` **存疑**
  - 校对端无法单方面结案、需提示人工介入的事项；译文处理反常需核实译者意图、缺失上下文无法断定、或存在多种合理译法需人工拍板定夺。
  - 凡依据已有规则或上下文足以确诊的，必须直接归入对应错误类型，不得滥用存疑。
