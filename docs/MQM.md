# MQM 类型

## 总览

- **准确 `accuracy`** 判命题内容、言外之意和术语是否一致。
- **通顺 `fluency`** 判句子是否成立、自然、可读。
- **得体 `fit`** 判表达是否适配文本类型、使用场景和项目约定。
- **排版 `design`** 判占位符、格式码、格式约定和长度是否合规。
- **原文 `source`** 记上游文本自身的问题，不计在译者头上。

## 准确 `accuracy`

准确只判命题内容、言外之意与术语，不判句子顺不顺。

- `accuracy/mistranslation` **错译**（critical）
  - 译文把原文的否定、指称、数量、关系或反义译错了。
- `accuracy/omission` **漏译**（critical）
  - 译文丢了原文的整句、从句、限定成分或条件，甚至整条输出为空。
- `accuracy/addition` **增译**（minor）
  - 译文多出原文没有的解释、串行或重复。
  - 必要的显化不算增译。
- `accuracy/untranslated` **未译**（critical）
  - 该译的内容仍是英文。
  - 品牌名、模组名和刻意保留的原样不算未译。
- `accuracy/do-not-translate` **应留原文**（major）
  - 译文译出了保留清单里要求原样的内容。
  - 判定只看保留清单，不靠品牌名推断。
- `accuracy/terminology` **术语不符**（critical）
  - 译名与冻结表、领域标准或社区标准不符。
  - 译文在同词多义时选错了义项。

## 通顺 `fluency`

通顺只判句子是否成立、自然、可读，不判意思对不对。

- `fluency/grammar` **语法**（major）
  - 译文句子成分残缺、语序错或搭配不当。
- `fluency/awkward` **生硬**（minor）
  - 译文句子语法成立，但读来有翻译腔，显得冗余或拗口。
- `fluency/punctuation` **标点**（minor）
  - 译文标点误用，引号或括号不配对，句末标点缺失。
- `fluency/typo` **错别字**（minor）
  - 译文出现错字、别字或形近字误用。
  - 术语用字错了，归 `accuracy/terminology`。

## 得体 `fit`

得体只判表达是否适配文本类型、使用场景和项目约定，不判意思对不对。

- `fit/register` **语域不符**（minor）
  - 译文口吻与文本类型不符，物品描述写成了说明书，按钮用了书面语，称呼上你/您混用。
- `fit/function` **功能不符**（major）
  - 译文没起到该 UI 元素应有的作用，按钮写成了句子，物品名写成了描述，提示写成了标题。
- `fit/tone` **语气不符**（minor）
  - 译文没译出原文的讽刺、紧急、玩笑或亲昵语气。
- `fit/culture` **文化错位**（minor）
  - 译文意象与原文设定冲突，中世纪奇幻里出现了现代网络用语，西幻里出现了中式典故。
- `fit/convention` **体例不符**（major）
  - 译文与项目约定不符，同模式句式不统一，固定提示语被改写。

## 排版 `design`

排版只判占位符、格式码、格式约定和长度，不判措辞。

- `design/markup` **格式码错**（major）
  - 译文里的占位符、格式码或标签有缺失、错位或语义错误。
- `design/format` **格式不符**（minor）
  - 全半角、中英混排空格或大小写与项目约定不符。
  - 术语的固定大小写错了，归 `accuracy/terminology`。
- `design/length` **长度超限**（major）
  - 译文超出按钮、提示框、物品名的可用长度。

## 原文 `source`

原文只记上游文本自身的问题，不计在译者头上。

- `source/defect` **原文问题**（neutral）
  - 原文本身有错误、歧义、占位符不全或不适宜内容。

## 档位

- `critical` 档会让读者理解错，或让内容不可用。
- `major` 档不影响理解，但明显影响使用或一致性。
- `minor` 档不影响理解与使用，只是观感或规范上的瑕疵。
- `neutral` 档表示不算译者的错，或暂不定级。
